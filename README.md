Welcome to my college notes repository!

This repository contains notes, summaries, examples, and other learning materials I've collected throughout my college studies. I use [Obsidian](https://obsidian.md/) to organize and maintain these notes.

The goal of this repository is to keep my learning materials organized, make them easy to revisit, and share them with anyone who might find them useful.

## What's inside?

The repository currently includes notes on:

- **Mathematics** — Number theory, modular arithmetic, Boolean algebra, and [LaTeX](https://www.latex-project.org/).
- **Programming** — Programming concepts and Python.
- **Algorithms** — Algorithm fundamentals, searching, and visual examples.
- **Exam Dates** — Upcoming exams, quizzes, and other academic dates.
- **Drawings** — Diagrams, sketches, and other visual notes.

The repository is a work in progress, so its contents and organization may change as I continue my studies.

## Using these notes

Most notes are written in Markdown and are intended to be viewed in Obsidian. Some notes use Obsidian-specific features, such as internal links and Canvas files.

You can browse the `.md` files directly on GitHub, but opening the repository as an Obsidian vault will provide a better experience.

## A small disclaimer

These are personal study notes, not official course materials. They may contain mistakes, incomplete explanations, or topics that are still being developed.

Feel free to use them as a reference, but double-check important information when studying.
